# Míster · Entrenamientos de fútbol

App de entrenamientos del **UE Sant Ildefons** para iPhone y navegador.

**Abrir la app:** https://laparcelitadelascartas-design.github.io/mister/

## Instalar en iPhone
1. Abre el enlace en **Safari**.
2. Pulsa **Compartir** y elige **Añadir a pantalla de inicio**.
3. Úsala siempre desde ese icono: funciona sin conexión y tus datos se guardan en el móvil.

En Android, usa el APK del repositorio privado *Futbol* (o instala esta misma web desde Chrome con «Añadir a pantalla de inicio»).

Este repositorio solo contiene la app ya montada. El código fuente está en el repositorio privado *Futbol* (`web/`).
